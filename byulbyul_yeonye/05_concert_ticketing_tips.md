# 콘서트·팬미팅 티켓팅 성공 팁, 취소표와 환불 규정까지 정리

인기 공연은 예매 오픈과 동시에 매진되는 경우가 많음.
{{red:준비를 미리 해두면 성공 확률을 높일 수 있어요.}}
예매 전에 환불 규정도 꼭 확인해야 함.

[이미지 1] 노트북과 스마트폰으로 예매 페이지를 보는 모습 (검색 키워드: 티켓 예매, 온라인 예매)

## 예매 전 준비

- 예매처 회원가입과 본인 인증을 미리 완료
- 결제 수단(카드, 간편결제)을 미리 등록
- 공연 공지에서 예매 오픈 시각과 선예매 조건 확인
- 안정적인 인터넷 환경과 기기 시간 동기화

{{blue:예매 시각은 서버 시계 기준이라 정확한 시간을 확인해두는 게 좋아요.}}

## 예매 당일 요령

- 오픈 몇 분 전에 접속해 대기
- 여러 기기로 중복 접속하면 제한될 수 있으니 예매처 안내 확인
- 좌석 선택은 빠르게, 결제까지 제한 시간 안에 끝내기
- 자동 입력 프로그램은 약관 위반이라 사용하면 안 됨

[이미지 2] 시계와 스마트폰 화면 (검색 키워드: 시계 스마트폰, 시간 확인)

## 취소표 잡기

- 예매 마감 직전이나 결제 기한이 지난 시점에 취소표가 풀리는 경우가 있음
- 예매처 알림 설정으로 취소표 소식 받기
- 취소표는 순식간에 사라지니 결제 정보를 미리 준비

## 환불 규정 확인

- 공연 예매 취소 수수료와 환불 기한은 예매처와 공연마다 다름
- {{red:취소 수수료 구간은 예매 전에 공지에서 직접 확인하세요.}}
- 프리미엄 가격이나 양도 관련 규정은 예매처 약관 기준
- 암표·불법 양도는 취소되거나 입장이 거부될 수 있음

[이미지 3] 티켓과 공연장 입구 (검색 키워드: 공연 티켓, 공연장 입장)

## 마무리

계정, 결제 수단, 일정 확인 세 가지만 미리 해도 훨씬 수월함.
규정과 수수료는 예매처 공식 공지로 최종 확인.
