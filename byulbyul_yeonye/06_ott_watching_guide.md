# 연말 몰아보기 OTT 구독 비교와 해지·환불 팁

연말에는 보고 싶은 작품이 몰려 OTT 구독을 고민하게 됨.
{{red:구독료와 혜택은 수시로 바뀌니 가입 전에 공식 페이지에서 확인하세요.}}
필요한 기간만 구독하고 해지하는 게 지출을 줄이는 방법임.

[이미지 1] 스마트폰으로 OTT 앱을 고르는 모습 (검색 키워드: OTT 앱, 스트리밍 서비스)

## 구독 고르는 기준

- 보고 싶은 작품이 어느 플랫폼에 있는지 먼저 확인
- 광고형·스탠다드·프리미엄 등 요금제별 화질과 동시 접속 수 비교
- 통신사 결합 할인, 제휴 카드 혜택 여부 확인
- 무료 체험이 있다면 종료일과 자동 결제 시점 메모

{{blue:한 달에 한 플랫폼씩 돌려 구독하면 비용을 줄일 수 있어요.}}

## 몰아보기 순서

- 공개 예정 작품 일정은 플랫폼 공지로 확인
- 시즌제 작품은 완결 시점에 맞춰 구독하면 효율적
- 시청 목록(찜)을 미리 만들어두면 구독 기간 안에 소화하기 쉬움

[이미지 2] 거실에서 태블릿으로 영상을 보는 모습 (검색 키워드: 태블릿 영상 시청, 거실 시청)

## 해지와 환불

- 해지는 구독 앱의 계정 설정 메뉴에서 가능
- 앱스토어(구글·애플)로 결제했다면 해당 스토어의 구독 관리에서 해지
- 해지해도 남은 이용 기간까지는 시청 가능한 경우가 많음
- {{red:환불 가능 여부와 조건은 서비스별 약관에 따라 달라요.}}
- 미사용 상태 청약철회 가능 여부는 약관과 소비자원 안내 확인

[이미지 3] 구독 결제 내역을 확인하는 모습 (검색 키워드: 결제 내역 확인, 카드 명세서)

## 마무리

구독 기간 메모, 요금제 비교, 해지 시점 확인 세 가지만 챙기면 낭비를 줄일 수 있음.
가격과 정책은 각 서비스 공식 안내로 최종 확인.
